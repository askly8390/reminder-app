# История изменений

## 1.3.0

- В списке по умолчанию отображаются пять напоминаний, остальные можно развернуть и свернуть.
- Добавлен календарь с полным месяцем без вертикальной прокрутки.
- В календаре отображаются будущие вхождения ежедневных, еженедельных, ежемесячных и ежегодных напоминаний.
- Добавлены переходы между месяцами, возврат к текущему месяцу и редактирование из календаря.
- Основное окно увеличено для удобного отображения календаря.

## 1.2.1

- Исправлен перенос данных, если новый файл хранилища уже был создан во время тестового запуска.
- Старые напоминания из версии 1.1.0 безопасно объединяются с текущим списком без дубликатов.

## 1.2.0

- Добавлено файловое хранилище напоминаний в пользовательской папке Windows.
- Добавлен автоматический перенос данных из версии 1.1.0.
- Добавлена безопасная запись и десять резервных копий.
- Запрещён одновременный запуск нескольких экземпляров приложения.
- Исправлена установка фокуса в поле названия при добавлении и редактировании.
- Во время работы с формой отложен показ новых всплывающих напоминаний.
- Добавлена проверка, загрузка и установка обновлений через GitHub Releases.
- Добавлена автоматическая публикация Windows-релизов через GitHub Actions.
